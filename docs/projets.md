# Projets mon-site — liens et dossiers

Chaque sous-projet est dans son propre dossier. **Toujours lancer `npm start` avant de tester.**

| Projet | Dossier | URL locale |
|--------|---------|------------|
| **ClipForge** (shorts YouTube) | `clipforge/` | http://localhost:3000/ |
| **Video Factory** | `video-factory/` | http://localhost:3000/studio |
| **VOANH AI** | `voanh/` | http://localhost:3000/voanh |
| **Agent de prospection** | `agent-prospection/` | http://localhost:3000/prospection |
| **Vidéo IA Qwen** | `video-ia-qwen/` | http://localhost:3000/video-ia-qwen |
| **Pages légales** | `legal/` | http://localhost:3000/legal/privacy.html |
| **TikTok callback** | `tiktok/` | http://localhost:3000/tiktok/callback.html |
| **Trading backend** | `trading_backend/` | (API Python) |
| **Pinokio** | `pinokio/` | (outil local) |

## Agent de prospection

```bash
npm start
```

**Lien valide : http://localhost:3000/prospection**

> Ne pas ouvrir le fichier HTML depuis GitHub : l'API BODACC nécessite le serveur Node.js.

Sur Render (si déployé) : `https://clipforge-studio.onrender.com/prospection`
