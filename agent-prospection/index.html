Prospection

Trouve les nouvelles entreprises d’un secteur, récupère un contact public validé, puis envoie une proposition comptable personnalisée — une par une ou en masse.

Mode fichier local. Lancez npm install && npm start puis ouvrez http://localhost:3000/prospection.

Paramètres

Auto élargit 30→365 j et ne garde que les contacts publics validés.
